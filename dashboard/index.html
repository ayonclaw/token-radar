How an implied value is derived

One function scores every protocol. No protocol's name is treated differently from any other's.

  1. Calibrate on the snapshot's own priced protocols

    — protocols carry both a TVL and a market cap. They are the only evidence the file holds about the size of a DeFi protocol next to its TVL, so the model fits its coefficients on them on every run:

    log10(market cap) = a + b × log10(base TVL) + m × relative 7-day move + category adjustment

    —

  2. Score every protocol that records no token, and rank them

    implied value = 10(a + b·log10(base TVL) + m·rel. growth) × category adjustment × tenure premium

    Base TVL is the TVL the snapshot prints with the week's own move taken back out, so a single week of growth enters the score once instead of twice. Relative growth is the protocol's 7-day change against the snapshot's own median change of —, so a protocol is marked up for outgrowing the field and down for falling behind it, never for the field's own direction.

What the fit cannot set, and how it is handled

The magnitude of the growth weight. The snapshot's market caps and its TVL print were read at the same instant, so the raw cross-sectional fit puts a negative sign on the 7-day move (—) — an artefact of a freshly-printed TVL sitting under a market cap set earlier, not a finding that growth destroys value. The model states the positive sign a reader expects and damps the magnitude. The cost is measurable and printed, not hidden: —

Tenure. None of the priced protocols is pre-token, so the file carries no evidence about what a long run with no token is worth. The tenure premium is a stated prior, not a fitted number: a multiplier in 0.80 to 1.20, monotone in the years a protocol has run with no token, identical for every protocol. It is the one term here the data cannot check, and this panel says so.

Category. Each category's residual after size, measured on the priced protocols and shrunk toward zero so a thin category cannot dominate. A category the fit never saw scores exactly 1.00.
